# Contributing to ucdpR

Bug reports and pull requests are welcome at
<https://github.com/christianoswald/ucdpR>. Please include a minimal
reproducible example with bug reports. New code should include tests and
should pass
[`devtools::check()`](https://devtools.r-lib.org/reference/check.html)
and
[`urlchecker::url_check()`](https://urlchecker.r-lib.org/reference/url_check.html).

By contributing, you agree to follow the project’s code of conduct.
