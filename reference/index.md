# Package index

## Discover

- [`ucdp_catalog()`](https://christianoswald.github.io/ucdpR/reference/ucdp_catalog.md)
  : List files in the official UCDP download catalog
- [`ucdp_search()`](https://christianoswald.github.io/ucdpR/reference/ucdp_search.md)
  : Search the UCDP catalog
- [`ucdp_versions()`](https://christianoswald.github.io/ucdpR/reference/ucdp_versions.md)
  : List available releases of a UCDP dataset

## Download and import

- [`ucdp_download()`](https://christianoswald.github.io/ucdpR/reference/ucdp_download.md)
  : Download an official UCDP data file
- [`ucdp_get()`](https://christianoswald.github.io/ucdpR/reference/ucdp_get.md)
  : Download and import a UCDP dataset

## Reproducibility

- [`ucdp_metadata()`](https://christianoswald.github.io/ucdpR/reference/ucdp_metadata.md)
  : Summarize UCDP provenance and data coverage
- [`ucdp_schema()`](https://christianoswald.github.io/ucdpR/reference/ucdp_schema.md)
  : Inspect the structure of a UCDP dataset
- [`ucdp_codebook()`](https://christianoswald.github.io/ucdpR/reference/ucdp_codebook.md)
  : Download an official UCDP codebook
- [`ucdp_version_history()`](https://christianoswald.github.io/ucdpR/reference/ucdp_version_history.md)
  : Download an official UCDP version history
- [`ucdp_replication_catalog()`](https://christianoswald.github.io/ucdpR/reference/ucdp_replication_catalog.md)
  : List publication-specific UCDP replication files
- [`ucdp_replication_download()`](https://christianoswald.github.io/ucdpR/reference/ucdp_replication_download.md)
  : Download files from the UCDP replication archive
- [`ucdp_cite()`](https://christianoswald.github.io/ucdpR/reference/ucdp_cite.md)
  : Retrieve citation guidance for a UCDP dataset
- [`ucdp_update_available()`](https://christianoswald.github.io/ucdpR/reference/ucdp_update_available.md)
  : Check whether a downloaded UCDP file has a newer catalog version

## Spatial and precision workflows

- [`ucdp_as_sf()`](https://christianoswald.github.io/ucdpR/reference/ucdp_as_sf.md)
  : Convert georeferenced UCDP data to an sf object
- [`ucdp_precision()`](https://christianoswald.github.io/ucdpR/reference/ucdp_precision.md)
  : Summarize spatial and temporal precision in UCDP event data
- [`ucdp_filter_precision()`](https://christianoswald.github.io/ucdpR/reference/ucdp_filter_precision.md)
  : Filter UCDP events by spatial and temporal precision

## Work with UCDP data

Convenience functions for recurring research tasks.

- [`ucdp_validate()`](https://christianoswald.github.io/ucdpR/reference/ucdp_validate.md)
  : Validate a UCDP dataset
- [`ucdp_fatalities()`](https://christianoswald.github.io/ucdpR/reference/ucdp_fatalities.md)
  : Summarize UCDP fatality estimates
- [`ucdp_aggregate()`](https://christianoswald.github.io/ucdpR/reference/ucdp_aggregate.md)
  : Aggregate UCDP event data to common analytical units
- [`ucdp_panel()`](https://christianoswald.github.io/ucdpR/reference/ucdp_panel.md)
  : Construct complete UCDP analytical panels
- [`ucdp_compare_versions()`](https://christianoswald.github.io/ucdpR/reference/ucdp_compare_versions.md)
  : Compare two releases of a UCDP dataset
