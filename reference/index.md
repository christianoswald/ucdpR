# Package index

## Discover

- [`ucdp_catalog()`](https://christianoswald.github.io/ucdpR/reference/ucdp_catalog.md)
  : List files in the official UCDP download catalog
- [`ucdp_search()`](https://christianoswald.github.io/ucdpR/reference/ucdp_search.md)
  : Search the UCDP catalog
- [`ucdp_versions()`](https://christianoswald.github.io/ucdpR/reference/ucdp_versions.md)
  : List available releases of a UCDP dataset

## Download and import

- [`ucdp_download()`](https://christianoswald.github.io/ucdpR/reference/ucdp_download.md)
  : Download an official UCDP data file
- [`ucdp_get()`](https://christianoswald.github.io/ucdpR/reference/ucdp_get.md)
  : Download and import a UCDP dataset

## Reproducibility

- [`ucdp_cite()`](https://christianoswald.github.io/ucdpR/reference/ucdp_cite.md)
  : Retrieve citation guidance for a UCDP dataset
- [`ucdp_update_available()`](https://christianoswald.github.io/ucdpR/reference/ucdp_update_available.md)
  : Check whether a downloaded UCDP file has a newer catalog version

## Work with UCDP data

Convenience functions for recurring research tasks.

- [`ucdp_compare_versions()`](https://christianoswald.github.io/ucdpR/reference/ucdp_compare_versions.md)
  : Compare two releases of a UCDP dataset
