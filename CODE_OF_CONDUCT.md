# Contributor Code of Conduct

This project follows the Contributor Covenant, version 2.1. Contributors are
expected to foster an open, welcoming, diverse, inclusive, and healthy
community. Instances of unacceptable behavior may be reported privately to
the package maintainer at christian.oswald@unibw.de.

The full covenant is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct.html>.
